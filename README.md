# 🔐 Captcha Crafters

An advanced, multi-layer CAPTCHA system designed to secure your applications with modern, accessible, and highly customizable challenges.  

---

## 🚀 Overview

**Captcha Crafters** combines multiple CAPTCHA mechanisms into one powerful package:

- ✅ Text-based CAPTCHA
- 🖼️ Image Recognition CAPTCHA
- 🔊 Audio CAPTCHA

Built with a modern tech stack that ensures high security, accessibility, and seamless integration.

---

## ✨ Features

### 🔡 Text-based CAPTCHA
Generates random strings using lowercase letters and numbers to verify human interaction.

### 🖼️ Image Recognition CAPTCHA
Presents users with a set of images, challenging them to identify correct ones to proceed.

### 🔊 Audio CAPTCHA
Generates audio files using **Google Text-to-Speech (gTTS)** and **PyDub**, allowing users to listen and type the correct text — improving accessibility for visually impaired users.

### 🛠️ API Integration
All CAPTCHA types are developed as APIs, making them easy to plug into any web application.

### 👤 User Authentication
Powered by **Supabase**, with support for email/password and OAuth (Google, GitHub).

## 🧰 Technology Stack

| Technology        | Purpose                                    |
|-------------------|--------------------------------------------|
| **React**         | Dynamic, component-based frontend         |
| **Flask**         | Lightweight Python backend & API server   |
| **Supabase**      | Authentication & database management     |
| **gTTS**          | Audio CAPTCHA generation                 |
| **PyDub**         | Audio manipulation                        |
| **PostgreSQL**    | Robust relational database               |

---

## 💡 Why These Technologies?

- **React:** Fast, responsive, and component-driven UI.
- **Flask:** Simple and flexible backend with Python power.
- **Supabase:** Seamless auth and database handling with minimal setup.
- **gTTS & PyDub:** Simplify audio generation and processing for enhanced accessibility.
